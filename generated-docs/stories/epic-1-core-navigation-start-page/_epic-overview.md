# Epic 1: Core Navigation & Start Page

## Description

Establish the foundational navigation structure and start page dashboard for InvestInsight. This epic creates the entry point for the application, replacing the template home page with a feature-appropriate dashboard that displays current batch status, quick navigation to key functional areas, and the ability to create new report batches.

## Stories

1. **Home Page Setup** - Replace template home page with InvestInsight entry point
   - File: `story-1-home-page-setup.md`
   - Status: Pending

2. **Main Navigation Structure** - Create top-level navigation menu with access to all major functional areas
   - File: `story-2-main-navigation-structure.md`
   - Status: Pending

3. **Start Page Dashboard** - Display current batch status, quick actions, and navigation links
   - File: `story-3-start-page-dashboard.md`
   - Status: Pending

4. **Create New Report Batch** - Initiate a new weekly or monthly report batch and transition to Data Preparation phase
   - File: `story-4-create-new-report-batch.md`
   - Status: Pending

5. **View Batch History** - Display historical batches with completion status and ability to view completed batches
   - File: `story-5-view-batch-history.md`
   - Status: Pending
