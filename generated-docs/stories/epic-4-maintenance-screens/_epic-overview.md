# Epic 4: Maintenance Screens - Financial Data

## Description

Implement maintenance screens for managing financial reference data including instruments, index prices, durations/YTM, betas, and credit ratings. Each screen provides full CRUD operations with audit trail support, search/filter capabilities, and workflow state restrictions to maintain data integrity during the approval process.
