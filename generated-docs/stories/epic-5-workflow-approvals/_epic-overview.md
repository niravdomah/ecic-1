# Epic 5: Workflow & Approvals

## Description

Implement the three-level sequential approval workflow for InvestInsight, managing the progression from Data Preparation through Level 1, Level 2, and Level 3 approvals to completion. This epic includes approval dashboards showing data completeness summaries, calculation status, report comments, approve/reject actions, and rejection handling that returns the workflow to Data Preparation phase.

## Stories

1. **Approval Dashboard Structure** - Create layout with workflow progress, data summary, and actions
   - File: `story-1-approval-dashboard-structure.md`
   - Status: Pending

2. **Level 1 Approval Process** - Implement first-level approval with data validation checks
   - File: `story-2-level-1-approval.md`
   - Status: Pending

3. **Level 2 Approval Process** - Implement second-level approval with portfolio confirmation
   - File: `story-3-level-2-approval.md`
   - Status: Pending

4. **Level 3 Final Approval** - Implement final approval with mandatory rejection reason
   - File: `story-4-level-3-approval.md`
   - Status: Pending

5. **Rejection Handling and Return to Data Preparation** - Handle rejection flow

   - Status: Pending

6. **Approval History Display** - Show previous approvals with timestamps and users
   - File: `story-6-approval-history.md`
