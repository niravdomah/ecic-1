# Epic 2: File Upload & Import Management

## Description

Implement the file upload and import functionality for InvestInsight, enabling users to upload portfolio files and other reference files (index data, Bloomberg, custodian files) through both manual upload and SFTP import. This epic provides a matrix view for portfolio files organized by portfolio and file type, a list view for other files, and a comprehensive modal for managing individual file uploads with validation error display.

## Stories

1. **Portfolio Files Matrix Dashboard** - Display grid of portfolio files with status indicators
   - File: `story-1-portfolio-files-matrix.md`
   - Status: Pending

2. **Other Files List Dashboard** - Display list of non-portfolio files with status indicators
